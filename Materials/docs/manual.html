One manual, two editions

SplatGen ships as two packages built from the same source. This page documents both. Everything carrying a blue PRO badge — and every section with a blue rail down its left edge — belongs to the Pro package only. Use Hide Pro-only in the toolbar above to read the page as a Standard user sees the panel.

SplatGen StandardCamera placement, rigs, the render queue, coverage validation and the complete dataset build, plus a preview of the point cloud and coverage it produces. No GPU, nothing to download, about 0.3 MB.
SplatGen ProEverything in Standard, plus GPU training with the managed CUDA runtime, the live preview, the Viewer and PLY / SOG export. About 26 MB.
What’s new in 5.1
  • Two editions. SplatGen now builds as Standard and Pro from one source. Standard is the dataset-building half and genuinely does not contain the trainer, the worker or the CUDA wheels — about 0.3 MB against Pro’s 26 MB, and no GPU needed. Both install as the extension splatgen, so installing one replaces the other, and datasets built by Standard are exactly what Pro trains from.
  • Resuming from a checkpoint actually resumes. Picking a Save Slot and pressing Start Training used to begin from scratch every time. Start re-pointed the dataset path at the version already selected, and Blender runs a property’s update callback on every assignment — including one that writes back the value already stored — which reset the Save Slot to New Run a moment before the run read it. The slot is now cleared only when the checkpoint it names has really gone. A second path, where the Enhanced First Step was enabled, skipped the resume entirely and re-seeded from the point cloud; a selected checkpoint now always continues the saved model.
  • Exports stand up the right way in other viewers. PLY and SOG are rotated from Blender’s Z-up world into the COLMAP/OpenCV frame that SuperSplat, PlayCanvas, Unity, Unreal and the browser viewers read, where +Y points down. 5.0.1–5.0.9 rotated the opposite way about X — a full 180° out, so every model arrived upside down and back to front. The higher-order spherical-harmonic bands are now rotated with the geometry too, so view-dependent highlights point where they should instead of staying in Blender’s frame. Files written by the affected releases carry a marker and are corrected, not double-rotated, when re-exported.
  • The Settings button works. It asked Blender to open Preferences from inside the panel’s popover, which Blender rejects there, so pressing it did nothing at all. It now opens Preferences from a real editor context, lands on Add-ons filtered to SplatGen, and reuses a Preferences editor you already have open. The operator also moved out of the training package, so it exists in both editions.
  • This manual covers both editions. Pro-only sections and controls are marked with a blue PRO badge and a blue rail; Hide Pro-only in the toolbar reads the page as a Standard user sees the panel.
Archived release notes (1.57–1.65)
  • 1.65 — Interface Responsiveness. Fixes the stall that made Blender’s whole interface feel laggy while the SplatGen panel was open. The Export button asked “is there anything to export?” twice per redraw, and answering it searched the filesystem — recursively, and, when no dataset had been chosen yet, starting from whichever folder Blender happened to be launched from. A single panel redraw could take about four seconds. The search is now bounded to the folders exports actually live in, an unset folder setting is treated as unset instead of as “the current directory”, and the answer is cached between redraws. Reading the dataset layout and the save list is cached the same way, so the size of a capture no longer changes how the panel feels.
    • 1.64 — Permanent Viewer Controls (final release). SplatGen no longer draws anything into the 3D Viewport: the button strip that used to sit along the bottom of every 3D View, and the plate drawn behind it, are gone, because they competed with Blender’s own gizmos, tools and navigation. Everything they did now lives permanently in 3. Viewer, which opens by default and keeps all seven visibility toggles and Frame Splat in fixed positions whether or not a Splat has been trained yet. A button with no data behind it is dimmed but still pressable — press it and it names the step that would create that data.
    • 1.61 — Version One Presets. The visible preset selector moved from the Beta panel to SplatGen_V1. All eight shipped recipes were rebuilt with native sgone_* settings, and choosing one from the dropdown applies it immediately — there is no separate Apply button any more. Old Beta-era preset files still load; their values are translated automatically.
    • 1.60 — Live Camera Settings. Use Global Camera Clipping now writes Clip Start / Clip End directly and permanently to every managed camera the moment it changes, instead of applying only during a render. Camera Preview shows the exact dataset clipping before you build anything.
    • 1.59. Blender's native Render window now opens automatically for the first dataset image and stays out of the way after that; closing or minimizing it does not stop the build. 3D View Sidebar is now the default interface location for new installs, and Wireframe Face Sources was removed — face-source meshes are unconditionally shown as wireframe now.
    • 1.58 — RGB-D Point Cloud Reconstruction. Point-cloud generation now back-projects rendered metric-depth maps instead of casting rays against the live mesh, and samples each point's colour from the matching RGB pixel — grass, fur, hair and alpha-cutout detail a mesh ray would have missed are now captured. Metric depth is a validated, always-written part of Dataset(Default), and the old Build SplatGen Training Metadata checkbox is gone: the enriched metadata it controlled is now always generated by Build Dataset.
    • The dataset build now nests one level deeper on disk, inside a SplatGen subfolder of whatever project folder you choose — existing projects built before 1.58 remain readable in their original location.
    • SplatGen_V1 remains the default trainer. The previous Beta trainer is still labeled Experimental Build — Coming Soon in the dropdown; nothing in the panel actually blocks it from training, but it receives no further development and its label says so.
    • Blender 5.0+, installed as an extension. Windows x64 only.
